# Структура проекта SnapShare

## Основные страницы

### 1. index.html - Главная страница с лентой контента
**Функциональность:**
- Лента публикаций (фото и видео)
- Истории в верхней части
- Боковая панель с рекомендациями
- Нижняя навигация на мобильных
- Инфинити-скролл для загрузки нового контента

**Компоненты:**
- Header с логотипом, поиском и иконками
- Stories carousel
- Feed с карточками постов
- Sidebar с рекомендациями
- Bottom navigation

### 2. profile.html - Страница профиля пользователя
**Функциональность:**
- Информация о пользователе
- Сетка публикаций
- Статистика (подписчики, подписки, публикации)
- Возможность редактирования профиля
- Подписка/отписка от пользователя

**Компоненты:**
- Profile header с аватаром и информацией
- Stats section
- Content grid (фото/видео)
- Edit profile modal
- Follow/unfollow buttons

### 3. upload.html - Страница загрузки контента
**Функциональность:**
- Drag & Drop для загрузки файлов
- Предпросмотр загружаемого контента
- Добавление описания и тегов
- Выбор категории
- Публикация контента

**Компоненты:**
- Upload area
- Preview section
- Form с полями для описания
- Category selector
- Publish button

### 4. messages.html - Страница сообщений и чата
**Функциональность:**
- Список диалогов
- Чат с конкретным пользователем
- Отправка сообщений
- Индикаторы набора текста и прочтения
- Поиск по сообщениям

**Компоненты:**
- Conversations list
- Chat window
- Message input
- User avatars
- Search bar

## Вспомогательные файлы

### main.js - Основной JavaScript
**Функции:**
- Инициализация всех компонентов
- Обработка лайков и комментариев
- Управление подписками
- Работа с localStorage
- Анимации и эффекты

### data.js - Мок-данные
**Содержимое:**
- Пользователи
- Посты (фото и видео)
- Комментарии
- Сообщения
- Истории

## Технические требования

### Библиотеки
- Anime.js - анимации
- Splide.js - карусели
- ECharts.js - визуализация данных
- Intersection Observer API - lazy loading

### Функциональные требования
- Адаптивный дизайн
- Инфинити-скролл
- Lazy loading изображений
- Local storage для данных
- Service worker для офлайн-работы

### Браузерная поддержка
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+
